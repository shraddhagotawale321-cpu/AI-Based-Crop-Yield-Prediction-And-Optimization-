# AI-Based-Crop-Yield-Prediction-And-Optimization-
AI-based Crop Yield Prediction system using Machine Learning to predict crop yield from agricultural and environmental data. Built with Python, Pandas, NumPy, Scikit-learn, and Streamlit, with a user-friendly web interface for accurate predictions and data-driven crop planning.
